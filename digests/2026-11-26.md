### Anthropic Engineering

[Migrating our Messages API to Rust](https://www.anthropic.com/research/migrating-api-to-rust) · 2026-11-25（来源日历日期）

Lance Martin、Jake Eaton、Arvin Aminpour、Emma Webb、Bharat Mediratta 和 Ravi Trivedi（均为 Anthropic Engineering 文章署名作者）披露：Rust 版 Messages API 在 4 月通过约 98% 测试，但在被比较的生产输入上，最初仅约四分之一和 Python 一致。团队用旧服务作对照，模型只实际推理一次，把相同输出回放给 Rust，并分阶段比较输入和输出。

一次差异来自工具描述缺失：代理把说明复制进本地文件，检验通过，工程师仍拒绝合并，因为线上需要从原服务获取描述。公开流量 9 月迁移；官方图 15 的 CPU/请求约降 70% 只覆盖一个区域，首 token 时间中位数约降 20% 只覆盖较短窗口内的客户 Claude Code 请求。文章页仅确认日期。

[官方检查点与回放](https://www.anthropic.com/research/migrating-api-to-rust#how-we-verified-the-migration)

### Vercel Changelog

[Workflow is 10x faster, again](https://vercel.com/changelog/workflows-speculative-execution) · 2026-11-25（来源日历日期）

Peter Wielander（Vercel Workflows 软件工程师）介绍 Workflow SDK 5.8：官方基准中步骤间 p75 额外开销从 85 ms 降到 7 ms；一个五轮、带流式输出和工具调用的 Agent 循环，框架开销从 3.0 s 降到 0.9 s。
