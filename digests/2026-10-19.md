graphify 把代码和项目资料整理成可查询的知识图谱，让编码 agent 先追踪依赖关系，再决定读取哪些文件。代码部分用 tree-sitter 解析语法树，区分直接提取与推断得到的连线，并输出交互图、报告和可复用的 graph.json；文档与媒体的语义处理则可能调用配置的模型。适合梳理陌生代码库和跨文件调用路径，但不能把代码解析的本地运行特性延伸成所有输入都不会外发。 首次收录于本日报，不代表首次登上 Trending。

2. [YuJunZhiXue/dsh-purge](https://github.com/YuJunZhiXue/dsh-purge) +423⭐ [JavaScript]

dsh-purge 是面向 DeepSeek Harness 的第三方本机红队评测插件，试图区分宿主策略拦截与模型自身的拒绝行为。它提供补丁状态、规则管理及受控演练界面，会改变本机宿主的默认策略与执行逻辑，因此属于需要审慎评估的安全研究工具。README 当前明确表示暂停维护，且新版 Harness 的兼容性不获保证；这里只记录项目用途与风险，不将其作为日常安全设置的替代。 首次收录于本日报，不代表首次登上 Trending。

3. [Comfy-Org/ComfyUI](https://github.com/Comfy-Org/ComfyUI) +154⭐ [Python]

ComfyUI 用节点图组织生成式 AI 工作流，把模型加载、条件输入、采样和媒体处理连接成可保存、复用的流程。工作流可保存为 JSON，并从支持的生成媒体中恢复流程与种子；自定义节点可扩展图像、视频、音频等任务，适合需要反复调整和复现生成过程的创作者。核心支持离线运行，但可选 API 节点及第三方扩展另有联网、费用和兼容性条件。 首次收录于本日报，不代表首次登上 Trending。

4. [Kruk2/jasna](https://github.com/Kruk2/jasna) +115⭐ [Python]

Jasna 在本地 GPU 上处理视频和图片的马赛克区域，提供图形界面、命令行及片段选择预览。它先检测并跟踪区域，再按镜头切分片段进行恢复，最后将结果合回原画面；基础模型采用 BasicVSR++，更慢的 LTX 路径属于支持者模型。适用范围应限于有权处理的素材，生成的细节不能视为被遮挡原貌的事实证据；不同模型还受显卡与授权条件限制。 首次收录于本日报，不代表首次登上 Trending。

5. [NVlabs/ASPIRE](https://github.com/NVlabs/ASPIRE) +94⭐ [Python]

ASPIRE 把机器人持续学习的产物做成可迭代的技能仓库，由 coding agent 反复练习、调试和改进感知动作代码，而非仅靠梯度更新模型权重。仓库提供仿真技能与实机示例，v1.0 报告在 80 个 LIBERO-Pro 任务上达到约 99% 成功率；这属于项目方给定任务与实验条件下的结果。它为具身 agent 研究提供了可复现实验入口，但生成代码拥有完整导入能力，仿真实验应隔离运行，实机控制需要另行校准与授权。 首次收录于本日报，不代表首次登上 Trending。
