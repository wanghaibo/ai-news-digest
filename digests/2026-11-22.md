### AG-UI

#### [Release 2026-11-21](https://github.com/ag-ui-protocol/ag-ui/releases/tag/release%2F2026-11-21)

Agent 恢复时，输入改了就重新走检查

AG-UI 新版 LangGraph 适配器在恢复时区分输入有没有变：图输入有变化，就开启新 run，由之前的检查重新判断；输入不变且能继续时，不再把客户端状态写一遍，以免累加型 reducer 重复计数。另一条独立更新来自 Python 的 OpenAI Agents 适配器：一次性审批绑定服务端暂停的工具调用和对应 agent，消费时检查有效期。跨 worker 或重启要靠部署方配置能原子记录消费的持久共享存储；审批只消费一次，也不等于外部业务写入只执行一次。

npm 的 TypeScript LangGraph 0.0.47 和 PyPI 的 Python LangGraph 0.0.48 是两套适配器，OpenAI Agents 改动来自 ag-ui-openai-agents 0.2.0。北京时间 11 月 22 日 02:04 发布，发行标签使用 UTC 日期。以审批一项排队变更后从另一个标签页继续为例，若请求参数已改，旧 run 的检查结果不应替代新检查；若外部已写入却丢了回执，业务仍需要操作标识、幂等或对账。后者是工程建议，不是该版本的保证。
